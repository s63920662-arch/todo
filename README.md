# Todo CLI

Простая консольная утилита для управления задачами на Python. Позволяет добавлять, просматривать, отмечать как выполненные и удалять задачи. Данные сохраняются в локальном JSON‑файле.

## Установка и использование

1. Сохраните файл `todo.py` на вашем компьютере.
2. Откройте терминал/командную строку в папке с файлом.
3. Запустите утилиту с нужной командой:

## Команды

| Команда | Описание | Пример |
|-------|---------|-------|
| `add "<описание>"` | Добавить новую задачу | `python todo.py add "Изучить Python"` |
| `list` | Показать все задачи | `python todo.py list` |
| `complete <ID>` | Отметить задачу как выполненную | `python todo.py complete 123e4567-e89b-12d3-a456-426614174000` |
| `delete <ID>` | Удалить задачу | `python todo.py delete 123e4567-e89b-12d3-a456-426614174000` |
| `--help` | Показать справку | `python todo.py --help` |

**Примечание:** ID задачи — это уникальный идентификатор, который отображается при выполнении команды `list`.
